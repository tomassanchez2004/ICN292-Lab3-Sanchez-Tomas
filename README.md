## Descripción
Repositorio correspondiente al Laboratorio 3 de la asignatura Sistemas de Información para la Gestión.
El trabajo desarrolla un MVP de automatización para la gestión de solicitudes de devolución de AndesHogar SpA utilizando n8n.
## Contenido del repositorio
- Informe del laboratorio en PDF.
- Informe del laboratorio en formato Word.
- Workflows de n8n exportados en formato JSON.
- Evidencias de las ejecuciones realizadas.
- Archivos necesarios para revisar y reproducir el trabajo.
## Reproducción
Los workflows pueden ser importados en n8n mediante la opción de importación de workflows utilizando los archivos `.json` incluidos en este repositorio.
Las credenciales utilizadas en n8n se mantienen fuera de los archivos exportados y no se incluyen en este repositorio.
